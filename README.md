# Wiom CSP — Prototypes

HTML lo-fi prototypes for the Wiom Partner (CSP) app. Each folder is one problem/feature being explored before Kotlin implementation in the main app.

## Workflow

1. Build HTML lo-fi prototype in a new folder.
2. Share with stakeholders for review.
3. Iterate until approved.
4. Implement approved design in the Kotlin app (`wiom-csp-app-apr09`).
5. Move folder to `archive/` once shipped.

## Conventions

- Folder names: `kebab-case` (no spaces, lowercase).
- Each prototype folder has its own `README.md` with context, decisions, and stakeholder feedback.
- Shared design tokens / CSS in `_common/` (added when needed).
